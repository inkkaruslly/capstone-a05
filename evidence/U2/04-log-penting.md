# U2 - Log Penting

Publish saat worker berhenti:

```text
run01-G01 | billing | HTTP 202
run01-G02 | technical | HTTP 202
run01-G03 | general | HTTP 202
run01-G04 | billing | HTTP 202
run01-G05 | technical | HTTP 202
5 event selesai dipublish.
```

Setelah worker dipulihkan, log menunjukkan `TICKET ASSIGNED` untuk G01-G05.
